# Worklog

Meaningful milestones, one file per entry in `entries/`. Do not append to this index.

## Files

`entries/YYYY-MM-DDTHHMMZ-author-slug.md` (UTC, so names sort by time). List `entries/` to find recent work.

## Entry Template

```markdown
---
date: YYYY-MM-DDTHH:MM:SSZ
author: name-or-agent
related:
  - CV1.DS1.US1
verification:
  - command or validation route
---

# Milestone title

## What changed

## Why it matters

## Verification
```
