# Arrastar a ordem sem rolagem automática

## Description

Os centros dos itens são medidos ao começar; a lista não rola sozinha na borda.

## Carrying Reason

A lista de presentes é curta; um componente de ordenação genérico seria mais código que o ganho.

## Impact

Em lista longa o jogador precisa arrastar em partes ou usar ↑ ↓.
